# Evidencia Metabase

Este documento agrupa las capturas de los dashboards creados en Metabase para
evidenciar RF1 a RF8 del SRS.

| Dashboard | Archivo | Requisitos |
| --- | --- | --- |

| Ventas | `docs/evidencia/metabase_ventas.png` | RF2, RF3, RF7, RF8 |

## Filtros Globales

Cada dashboard incluye filtros globales conectados a las preguntas SQL:

- Fecha de compra
- Categoria
- Ciudad
- Dispositivo
- Metodo de pago

Las preguntas SQL estan documentadas en `docs/metabase_preguntas_dashboards.md`.
